# Explainable AI-Based Intrusion Detection System for SDN

An ML-based Intrusion Detection System (IDS) for Software-Defined Networks
that classifies network traffic and uses Explainable AI (XAI) to explain
individual predictions.

## Objectives

- Detect normal and malicious network traffic.
- Compare Logistic Regression, Random Forest, and XGBoost.
- Explain predictions using SHAP.
- Evaluate detection performance beyond accuracy.
- Measure inference time and computational overhead.
- Provide an interactive Streamlit dashboard.

## Technology Stack

- Python
- Pandas, NumPy, Scikit-learn
- XGBoost
- SHAP
- Streamlit
- Matplotlib, Seaborn
